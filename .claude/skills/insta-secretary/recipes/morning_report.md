# 朝のひとこと報告

毎朝、今日のタスクの状況をひとまとめにして届ける仕事。本人が朝いちばんに「今日なにをすればいいか」をひと目で分かるようにする。

## いつ使うか

- 「毎朝レポートして」「朝に今日やることをまとめて届けて」
- 「今日のタスク教えて」「期限切れになってるものある？」

## 前提

- **タスクメモがあること。** `templates/tasks.md` の型で書かれたメモが、報告の材料になる
  - まだ無ければ、`templates/tasks.md` をコピーして本人用のタスクメモを作る。書き方は「1行1タスクのチェックボックス式。期限があるものは `｜期限:`、誰かの返事を待っているものは `｜返信待ち開始:` を行末に添える」とやさしく説明する
- **届け先を決めること。** 最初にこう聞く（「記号だけの返事でOKです」と添える）
  - **A. チャットで受け取る** — 朝、本人が「レポートして」と言ったらその場で出す。準備ゼロで今日から使える
  - **B. Discordに自動で届く** — 毎朝決まった時間にDiscord（グループチャットアプリ）のチャンネルへ送る。`capabilities/discord_notify.md` を読んでから設定する
- **（任意）Googleカレンダー連携。** 今日の予定も一緒に載せたいときだけ。`capabilities/google_calendar.md` を読んでから設定する。使うのは**読み取りだけ**（予定を見るだけで、書き換えはしない）と本人に伝える

## 進め方

1. タスクメモを開き、今日の日付を基準に中身を仕分ける
2. 次の**4項目・この順番**で報告を組み立てる
   1. **今日の動き**（カレンダー連携をしている場合のみ）— Googleカレンダーから今日の予定を読み取って載せる
   2. **【締切】今日までのタスク**
   3. **【超過】期限を過ぎているタスク** — まだ「済」になっていないもの
   4. **【待ち】48時間以上うごきのない返信待ち** — 片づくまで毎朝載せ続ける。初回に「この欄はしつこく出ますが、忘れ防止のためのわざとです」と伝えておく
3. 件数がゼロの欄は「なし」と一行だけ書く。欄そのものは消さない — 毎朝同じ形だから、安心して流し読みできる
4. 届け先に合わせて出す
   - **A（チャット）**: 「レポートして」と言われたら、その場で組み立てて返す
   - **B（Discord）**: `capabilities/discord_notify.md` の手順でチャンネルへ送る
5. **毎朝の自動実行にする場合**（Bを選んだときなど）
   - OS標準のスケジュール機能で毎朝の実行を設定する（macOSなら launchd ＝決まった時間にプログラムを動かすOSの仕組み）
   - `capabilities/patrol.md` の**見回り**を必ず組み込み、動いたかどうかの記録を `_patrol/` に残す
   - **「PCがスリープ（ふたを閉じて休んでいる状態）だと動きません」と必ず伝える。** 朝まで起こしておくか、届かない日もあると了解してもらってから設定する

## できあがりの形

```
☀️ 8/29（金）朝のひとこと

今日の動き: 10:00 打ち合わせ（Zoom）
────────────
【締切】今日まで
- ○○さんへ資料を送る

【超過】期限を過ぎているもの
- なし

【待ち】48時間うごきなし
- △△さんのDM（8/26〜）→ 片づくまで毎朝再掲します
```

- カレンダー連携をしていないときは「今日の動き」の行ごと出さない
- どの欄も、ゼロ件なら「なし」の一行だけ

## やらないこと

- タスクを勝手に「済」へ変えない。終わったかどうかを決めるのは本人だけ
- タスクメモの書き換えは**追記のみ**。既存の行を消したり書き直したりしない（直したい箇所を見つけたら、本人に伝えてお願いする）
- レポートを口実に、送信や投稿など報告以外の操作をしない（`safety.md` ①）

## うまくいかないとき

「朝に届かなかった」と言われたら、この順番で確認する。

1. **PCは起きていたか** — スリープしていたら仕組みは動けない。まずここを疑い、責めない言い方で確認する
2. **`_patrol/` のログ** — 見回りの記録を開く。alert（自動処理のSOS）が残っていたら、その内容をやさしい言葉で報告する
3. **届け先の設定** — Discordの送り先チャンネルや設定が変わっていないか、`capabilities/discord_notify.md` を見ながら確かめる

3回直しても安定しなければ、正直にそう伝えて、当面はA（朝に「レポートして」と言ってもらう方式）への切り替えを提案する。
