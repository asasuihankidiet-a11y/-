# Zoom録画の自動アーカイブ

Zoomのクラウド録画（Zoomのサーバーに保存される録画データ）を、自動でYouTubeに「限定公開」でアップロードし、終わったら知らせる常駐の仕組みを作るレシピ。8つのレシピの中でいちばん本格的な自動化なので、準備の確認をいつも以上にていねいにやる。

## いつ使うか

- 「Zoomの録画、毎回YouTubeに上げるのが面倒」
- 「講座の録画、自動でアーカイブしておいて」

## 前提

作り始める前に、次のチェックリストを**上からひとつずつ**本人と確認する。まとめて聞かず、1項目ずつ「これはOKですか？」と進める。

- [ ] Zoomの**有料プラン**に入っていて、**クラウド録画**（録画をZoomのサーバーに保存する機能）がONになっている
- [ ] Zoomの鍵（APIキー＝Zoomと秘書をつなぐ入館証）の設定が済んでいる → `capabilities/zoom_api.md`
- [ ] **YouTubeチャンネル**を持っていて、OAuth設定（Googleに「この秘書がアップしてもいいですよ」と許可を出す手続き）が済んでいる → `capabilities/youtube_api.md`
- [ ] （任意）完了をDiscordに通知したい場合 → `capabilities/discord_notify.md`
- [ ] 日中、**PCが起きている**こと（この仕組みはPCが動いている間だけ働く）

あわせて、着工前に次の2点を包み隠さず伝える（safety.md ⑥）:

- YouTubeのAPIには**1日の利用枠（クォータ＝その日に使える量の上限）**があり、アップできるのは**実質1日6本程度まで**
- 作りたてのAPI設定では、アップした動画が**「非公開」（本人以外は誰も見られない設定）に固定される**場合がある。その際は**Googleへの審査申請**（「まっとうな用途です」と申請して制限を外してもらう手続き）が必要になる

## 進め方

1. **前提チェック** — 上のチェックリストをひとつずつ一緒に確認する。ひとつでも未完なら、まずそこを片づけてから先へ進む
2. **鍵の準備** — `capabilities/zoom_api.md` と `capabilities/youtube_api.md` の手順どおりに案内する。鍵は決めた保管ファイルにだけ置く（safety.md ④）
3. **仕組みの構築** — 次の流れで動く常駐処理を作る:
   1. 定期的（例: 10分おき）に、Zoomに新しいクラウド録画がないか確認する
   2. 新しい録画が見つかったら、PCにダウンロードする
   3. YouTubeへ**「限定公開」**（URLを知っている人だけが見られる設定）でアップロードする
   4. タイトルと説明文は、録画名と日付から自動で作る（例: 「◯◯講座 2026-08-29」）。説明文に毎回入れる定型の一文（プロフィールへの案内など）があれば、`assets/brand.md` の設定を使う
   5. `assets/style.md`（文体ルール）がすでにあれば、説明文の文面をそれに合わせる
   6. Discord通知を設定していれば、**動画URL付き**で完了を知らせる
   7. `processed.json`（処理済みの録画を覚えておく記録ファイル）に録画のIDを書き込み、同じ録画を二度アップしないようにする
4. **初回は1本だけテスト** — いきなり常駐させない。**録画1本だけ**を通しで処理し、アップされた動画を本人に見てもらう。タイトル・説明文・限定公開になっているかを確認してもらい、**OKが出てから**定期実行を開始する（safety.md ⑤の「まず小さく試す」）
5. **見回りを必ずセットにする** — `capabilities/patrol.md` の見回りを組み込む。アップに失敗したら自動で**最大3回**までやり直す。それでも直らなければ `_patrol/alert.md` に記録して本人に知らせる

## できあがりの形

- 会議や講座が終わってしばらくすると、YouTubeに限定公開の動画が自動で並んでいる
- タイトルと説明文は録画名・日付から生成済み
- （設定していれば）Discordに動画URL付きの完了通知が届く
- `processed.json` に処理済みの記録が貯まり、二重アップは起きない
- おしごとカード（`templates/oshigoto_card.md`）に、確認の間隔・通知先・アップ設定を確定版として残してある

## やらないこと

- **「公開」設定でのアップは絶対にしない。** 必ず限定公開。世界中に見える状態にするかどうかは、本人がYouTube上で自分の手で切り替える（safety.md ①）
- **Zoom側の元録画は削除しない**（safety.md ②）。容量を整理したくなったら、対象の一覧を見せて本人に判断してもらう
- 録画そのものの編集・カットはこのレシピでは扱わない

## うまくいかないとき

まず「認証の問題」なのか「枠・容量の問題」なのかを切り分ける。

- **認証切れ** — エラーに「認証」「401」「token」などの言葉が出るとき。GoogleやZoomに出した許可の期限が切れた状態なので、`capabilities/youtube_api.md`（Zoom側なら `capabilities/zoom_api.md`）の手順で再ログインを案内する
- **枠切れ・容量切れ** — エラーに「quota」「limit」などの言葉が出るとき、またはその日すでに6本近くアップした後。壊れたわけではないので、その録画は**翌日に回す**。`processed.json` にはまだ記録せず、翌日の確認で拾えるようにしておく
- どちらでもないエラーが3回続いたら、`_patrol/alert.md` に記録して本人に報告し、指示を待つ。原因はやさしい言葉で説明し、相手を責める言い方はしない
