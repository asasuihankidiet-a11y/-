# フォルダ片づけ — 散らかったフォルダを安全に整えて、やりかけを見える化する

## いつ使うか

こんな声がかかったら、このレシピで動く。

- 「ダウンロードフォルダがぐちゃぐちゃだから整理して」
- 「やりかけの一覧出して」

「片づけて」「もうどこに何があるかわからない」のような相談も、このレシピの出番。

## 前提

- 対象フォルダの場所を本人から教えてもらえること（デスクトップ、ダウンロードなど）
- `safety.md` を読み終えていること。特に**②元データは守る**がこのレシピの背骨になる
- 片づけとは「移動」と「名前の変更」だけを指す。削除はこのレシピの仕事に含まれない

## 進め方

1. **対象と困りごとを聞く**
   - どのフォルダを片づけたいか、場所を教えてもらう
   - 「いちばん困っていることは何ですか？」と聞く。「探すのに時間がかかる」「やりかけがどれか分からない」など、困りごとによって整理の力点が変わる
   - 質問はひとつずつ。フォルダの場所が曖昧なら、候補を A / B / C ＋「その他」で出して選んでもらう
2. **現状を調べて報告する**
   - 中身を調べて、次の3点を短くまとめて見せる:
     - ファイルの数
     - 種類の内訳（画像が何件、書類が何件、動画が何件…のように）
     - いつ頃のものが多いか（例:「半分は今年の春より前のものです」）
   - この時点ではまだ何も動かさない。見せるだけ
3. **整理方針を提案して、OKをもらう**
   - フォルダ分けのルール（例:「画像」「資料」「配信ネタ」のような、本人の仕事に合わせた分け方）と、名前の付け方（例:「日付_内容.拡張子」。拡張子＝ファイルの種類を表すおしりの文字）を、案としてひとつ出す
   - 「こう分けようと思いますが、どうですか？」と聞き、本人のOKが出るまで手を動かさない。直したいところがあれば方針を書き直す
4. **お試しで2〜3件だけ動かす**
   - 方針どおりに、手始めの2〜3件だけ移動・リネーム（名前の変更）を行い、「元の名前 → 新しい名前と場所」を並べて確認してもらう
   - 本人のOKが出たら、残りを全部片づける。違和感を言われたら方針を直して、また3件から（safety.md ⑤の「まず小さく試す」と同じ考え方）
5. **変更一覧をファイルで残す**
   - 「元の場所 → 新しい場所」の対応表を、対象フォルダの中に `片づけ記録_日付.md` のような名前で保存する
   - これがあれば、いつでも元に戻せる。保存したことと置き場所を本人に伝える

### やりかけファイルの見える化

- 途中で止まっているファイルには、名前の頭に **【途中】** を付ける運用を提案できる（例:「【途中】9月リール台本.txt」）。付けるかどうかは本人が決める
- 「やりかけ一覧出して」と言われたら、対象フォルダの【途中】付きファイルを一覧にして報告する
- **【途中】を外すのは、本人から「これは終わったから外して」と指示があったときだけ。** ファイルの中身から「終わってそう」と秘書が判断して外すことはしない

## できあがりの形

- 方針どおりに分類されたフォルダ（元のファイルはすべて移動か名前の変更のみで、1件も失われていない）
- 変更一覧ファイル（元の場所 → 新しい場所の対応表）
- 希望があれば、【途中】ルールで印の付いたやりかけファイルたち

## やらないこと

- **削除は一切しない**（safety.md ②）。「もう要らなそう」に見えるファイルも消さない。ゴミ箱に入れることもしない
  - ※本人から削除を強く求められた場面の扱いは safety.md ②に従う（何を消すか先にリストで示し、はっきり承認された分だけ）。このレシピの側から削除を提案することはない
- 中身を勝手に書き換えない。触るのは「置き場所」と「名前」だけ
- 元に戻せない状態を作らない。変更一覧を残す前に大量の移動をしない
- 本人のOKなしに残り全部へ進まない

## うまくいかないとき

- **どこに分類すべきか迷うファイルが出たら**、勝手に判断しない。対象フォルダの中に「迷い箱」フォルダを作ってそこに集め、あとでまとめて「これはどこに入れますか？」と本人に確認する
- 名前を変えると開けなくなりそうなファイル（何かのアプリが場所を覚えていそうなもの）に気づいたら、動かす前に「これは動かすと不具合が出るかもしれません」と伝えて指示を仰ぐ
- 移動の途中でエラーが出たら、そこで止めて、どこまで終わったかを変更一覧と照らして正直に報告する（safety.md ⑥）
