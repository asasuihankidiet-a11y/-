# 文体クローン — 本人の書き方のクセを覚えて、以後ずっと反映する

本人の過去の文章から「文体ルール」（その人らしい書き方のクセをまとめたメモ）を作り、`assets/style.md` に保存する。作ったあとは、秘書が書く文章すべてにこのルールを反映する。

## いつ使うか

- 「私の文体を覚えて」「私っぽい文章にして」と言われたとき
- 「秘書が書く下書き、なんか他人っぽいんだよね」と言われたとき

すでに `assets/style.md` があるのに違和感を指摘されたときも、このレシピの手順6（育てかた）に従う。

## 前提

- `safety.md` を読んでいること
- 素材にできるのは**本人が過去に書いた文章だけ**。本数の目安は最低3本、できれば10本以上
- できあがりの保存先は `assets/style.md`。ブランドの世界観（`assets/brand.md`）とは別物 — brand.md は「何を大事にしているか」、style.md は「どう書くか」を扱う

## 進め方

1. **素材を出してもらう。** 「過去にご自身で書いた文章を、最低3本（できれば10本以上）見せてください」とお願いする。Threadsのポスト、Instagramのキャプション（投稿につける説明文）、ブログ、メルマガ、LINEの配信文など、本人が書いたものなら何でもよい。チャットに貼り付けでも、ファイルの場所を教えてもらう形でもよい。集めながら「これは調子が出てた」「これは代筆」のような補足があればメモする
2. **クセを分析する。** 集まった文章を、4つのかたまりで読み込む
   - **リズム** — 文の長さ（短くたたみかけるか、長くゆったりか）と、改行・段落の呼吸（1行ごとに空けるか、かたまりで書くか）
   - **言葉えらび** — よく出る語尾（「〜です」「〜だよね」「〜かも」）、つい使う決まり文句、そして素材に一度も出てこない**使わない表現**（強い言い切り・業界用語・煽り言葉など）
   - **飾り** — 絵文字と記号の種類・量・置く位置（「！」「…」「✨」なども）
   - **読者との距離感** — 呼びかけ方（「あなた」「みんな」「〜な人へ」）、書き出しの入り方、締めの着地のさせ方
3. **`assets/style.md` に「ルール＋実例」の形でまとめる。** ルールだけ書いて終わりにしない。必ず本人の文章からの実例を添える（下の「できあがりの形」を参照）。ファイルの先頭に、素材にした本数と作成日を書いておく
4. **本人に検証してもらう。** 同じお題の短い文章を、「いつもの秘書の文」と「`assets/style.md` を通した文」のビフォー・アフター形式で見比べてもらう。「アフター側、ご自身が書いた文章として違和感ないですか？」と聞き、感想をもらってルールを直す。直したらもう一度短文で確かめる
5. **以後の運用を宣言する。** 「これからポストの下書きやキャプションなど、文章を書く仕事では必ずこのルールを先に読んでから書きます」と伝える。実際に、**文章を書く仕事に取りかかる前は必ず `assets/style.md` を読む**（例: `recipes/voice_to_threads.md` のポスト作成時）
6. **育てかた。** 「なんか私っぽくない」と言われたら、直す前にまず「どのあたりが違いましたか？ 語尾？ 絵文字？ リズム？」と聞く。本人の答えを `assets/style.md` にルールとして追記し、追記した内容をひとことで報告する。同じ違和感を繰り返させないのが腕の見せどころ

## できあがりの形

`assets/style.md` は、観点ごとに「ルール＋実例」のセットで書く。例:

```
## 語尾
- ルール: 断定を避け、「〜かも」「〜な気がする」で柔らかく着地することが多い
- 実例: 「これ、意外とみんなやってないかも」（2026-05のThreadsポストより）

## 改行と段落のリズム
- ルール: 1〜2文ごとに空行を入れ、画面上で詰まって見えないようにする
- 実例: （素材のInstagramキャプションの冒頭3行をそのまま引用して貼る）

## 使わない表現
- ルール: 「〜すべき」「絶対に」のような強い言い切りは使わない
- 補足: 素材10本のどこにも出てこなかった表現は、ここに随時追記していく
```

## やらないこと

- **他人の文体の複製は断る。** 有名人・他の発信者の文章を「この人みたいに書いて」と渡されても、素材にしない。「文体は本人のものなので、ご自身の過去の文章だけを素材にしています」と理由を添えて断る
- 素材の元ファイルを消したり書き換えたりしない（作業はコピーと読み取りだけ）
- ルールを本人に無断で書き換えない。追記・修正はすべて本人に報告する
- 文体を真似ても、投稿そのものはしない。渡すのは下書きまで（`safety.md` ①）

## うまくいかないとき

- **サンプルが少なくて特徴が掴めない** — できるふりをしない。「3本だと語尾のクセまでは見えるのですが、書き出しのパターンまでは掴めませんでした。あと何本か見せてもらえますか？」のように、掴めた部分と掴めていない部分を正直に伝えて、本数を増やしてもらう
- **時期によって文体がバラバラ** — 「最近の文章と1年前の文章で書き方が変わっていますが、どちらに寄せますか？」と聞き、本人が選んだ側を基準にする
- **検証で「適用後もしっくりこない」が続く** — 3回直しても違和感が消えないときは、正直にそう伝え、「いちばん『自分らしい』と思う1本を選んでもらい、それを手本に作り直す」やり方を提案する
