# 音声の文字起こし

## これは何の道具か

録音（ボイスメモ・スタエフ・Zoomの音声など）を、読める文章データに変えるための道具。本人に説明するときは「文字起こし＝録音を文章にすること」と一言添える。ポスト作成・議事録・アーカイブ貯金など、多くのレシピの入り口になる基礎道具。

やり方は2つあり、どちらを使うかは状況で選ぶ。

- **方式A: ローカルWhisper（faster-whisper）** — 自分のPCの中だけで動く、Python製の無料文字起こしプログラム。音声がPCの外に出ない
- **方式B: Gemini API** — Googleのサービスに音声を送って文章にしてもらう窓口（API＝サービス同士をつなぐ窓口）。準備が手軽

### 選び方の目安

| 状況 | おすすめ | 理由 |
|------|---------|------|
| 内緒の内容（未公開の企画・受講生の個人情報など） | 方式A | 音声がPCの外に出ない |
| 過去回を何十本もまとめて処理したい | 方式A | 何本やっても無料 |
| とにかく早く1本試したい | 方式B | 準備が数分で終わる |
| PCの空き容量が少ない・動作が重くなるのが心配 | 方式B | 大きなダウンロードが不要 |
| 方式Aの準備でつまずいた | 方式B | 逃げ道としてすぐ切り替えられる |

迷ったら本人に「この録音、外部のサービスに送っても大丈夫な内容ですか？」とひとこと確認してから選ぶ。

## 準備の手順

### 方式A: ローカルWhisper（faster-whisper）

1. Pythonがあるか確認する。ターミナルで `python3 --version` を実行し、バージョン番号が出ればOK。出なければ、Pythonの導入から案内する（本人には「Python＝この道具を動かすための土台となるソフト」と説明する）
2. 道具を入れる: `pip3 install faster-whisper`
3. 初回の実行時に、変換用のモデル（＝文字起こしの頭脳にあたるデータ）が自動でダウンロードされる。目安は small モデルで約0.5GB、精度重視の大きなモデルだと3GB近く。**始める前に「最初だけ数百MB〜数GBのダウンロードがあります。少し待ちますが2回目からは速いです」と必ず伝える**

実行はこの形が基本:

```python
from faster_whisper import WhisperModel

model = WhisperModel("small")  # 初回はここでモデルが自動ダウンロードされる
segments, info = model.transcribe("voice.m4a", language="ja")
text = "".join(s.text for s in segments)
print(text)
```

- モデル名は `small` から始める。精度が物足りなければ `medium` を試す（大きいほど正確だが、ダウンロードも処理時間も増える）
- 精度と時間のバランスは、まず1本試した結果を見せてから本人に選んでもらう

### 方式B: Gemini API

1. 本人にGoogle AI Studio（Googleが用意しているAPIキー発行ページ）を開いてもらい、無料のAPIキーを発行してもらう（APIキー＝サービスを使うための入館証のような文字列、と説明する）
2. 発行されたキーは `.env` に保存する（例: `GEMINI_API_KEY=...`）。チャットに貼らないよう先に伝えておく（safety.md ④）
3. 短い音声はそのまま送れる。**大きいファイルはFile API（＝大きな荷物用のアップロード窓口）を使って先にアップロードしてから文字起こしを頼む**

## 使い方のポイント

- まとめ処理は必ず**2〜3本（または録音の冒頭2〜3分）だけ試す → 本人に見てもらう → OKが出たら残り全部**の順で進める（safety.md ⑤）
- できあがった文章はテキストファイルで保存する。元の音声ファイルは消さない・動かさない（safety.md ②）
- 「えー」「あのー」などの言いよどみを整えるかどうかは、最初に本人に確認する。整えた場合も、元のままの版を残しておく
- 長い録音は処理に時間がかかる。目安の待ち時間を先に伝えてから始める
- 文字起こしのあとポストなどに加工するときは、`assets/style.md`（文体ルール）があればそれに合わせる

## 気をつけること

- **APIキーは `.env` にだけ書く。**チャット本文・コード内・共有ファイルには書かない（safety.md ④）
- 方式Bには無料枠があるが、大量に使うと課金される可能性がある。**無料枠を超えそうな量を処理する前に、必ず目安を伝えてOKをもらう**（safety.md ③）。金額の目安を口にするときは、記憶で言わず、その時点の公式料金ページで無料枠と単価を確かめてから伝える（料金はよく変わるため）
- 方式Aのモデルダウンロード（smallで約0.5GB〜大きいものは3GB近く）は、通信量や空き容量が気になる環境では事前に一声かける
- 文字起こしは完璧ではない。固有名詞・人名・専門用語は間違いやすいので、「名前や専門用語は念のため確認してください」と添えて渡す
- 内緒の内容かどうかの判断は秘書が勝手にしない。迷ったら本人に聞き、迷いが残るなら方式A（PCの外に出ない方）を選ぶ
