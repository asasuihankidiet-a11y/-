# Discordへの通知

## これは何の道具か

自動処理の結果やお知らせを、本人のDiscordチャンネルに届けるための道具。「Zoomの録画をアーカイブし終えました」「見回りでエラーを見つけました」のような報告を、本人がふだん見ている場所に置いておける。

通知を送るだけなら、**ウェブフック**がいちばん簡単。本人には「ウェブフック＝チャンネルに紐づいた専用の投稿口URL。このURLに文章を送ると、そのチャンネルに書き込まれる仕組み」と説明する。

ボットを常駐させる方式もあるが、それは「返事を受け取る」「コマンドで操作する」など、もっと高度なことをしたくなったときの発展形。通知だけならウェブフックで足りるので、最初からボットを提案しない。

## 準備の手順

ウェブフックの発行はDiscordの画面での操作なので、本人にやってもらう。次の道順をそのまま伝える。

1. Discordで、通知を受け取りたいサーバーを開く
2. **サーバー設定 → 連携サービス → ウェブフック → 新規作成** の順にクリック
3. 名前（例:「AI秘書」）と、通知を流すチャンネルを選ぶ
4. **「ウェブフックURLをコピー」** を押してもらう
5. コピーしたURLを `.env` に保存する（例: `DISCORD_WEBHOOK_URL=...`）。**チャットに直接貼らず、`.env` に書き込む形で受け取る**（safety.md ④）

保存できたら、送信テストをして動作を確かめる:

```bash
curl -H "Content-Type: application/json" -d '{"content":"AI秘書からのテスト通知です"}' "$DISCORD_WEBHOOK_URL"
```

チャンネルにこの一文が届けば準備完了。届いたかどうかは本人に画面で確認してもらう。

補足:

- 通知専用のチャンネル（例: `#秘書からの連絡`）を先に作ってもらうと、他の会話に埋もれない。チャンネル作成は本人の操作なので、必要なら道順ごと案内する
- 用途が増えたら（朝の報告用・エラー連絡用など）、ウェブフックはチャンネルごとに複数作れる。`.env` には `DISCORD_WEBHOOK_MORNING=...` のように用途がわかる名前で分けて保存する

### 本人に伝える安心材料

- このURLでできるのは、**選んだそのチャンネルに投稿することだけ**。サーバーの設定変更や、他のメッセージを読むことはできない
- ただしこのURLは、持っている人なら誰でも使えてしまう**鍵のかかっていない専用ポスト**。人に渡さない・画面写真に写さないこと
- もし漏れた心配があっても大丈夫。同じ画面からウェブフックを削除して作り直せば、古いURLはただちに無効になる

## 使い方のポイント

- 通知は「本人への報告」に使う。フォロワーや受講生が見る公開チャンネルへの投稿口としては使わない。設定時に「このチャンネルは、ご自身（またはチーム）だけが見る場所ですか？」と確認する
- どんな仕組みに通知を組み込むかは、おしごとカード（templates/oshigoto_card.md）に書いて合意してから。勝手に通知先や頻度を増やさない
- 常駐する仕組み（Zoom録画の自動アーカイブなど）に組み込むときは、見回り（capabilities/patrol.md）のalert通知先としても使うと、SOSに気づきやすくなる
- 通知文は短く。1行目だけで「何が・どうなったか」がわかる形にする。基本の型:

  ```
  ✅ 8/29のZoom録画をYouTubeに保存しました
  タイトル: 講座第3回 / 保存先: 限定公開リンクは _patrol/ の記録を参照
  ```

- 文面のトーンは assets/style.md がある場合はそれに合わせ、なければ短く事務的に。絵文字は先頭の状態マーク（✅ / ⚠️）程度にとどめる
- 1通あたり2000文字までの制限がある。長い報告はファイルに保存し、通知には要約と保存場所だけを書く
- 深夜に通知が飛ぶ仕組みになりそうなら、時間帯を本人に確認する

## 気をつけること

- **ウェブフックURLは `.env` にだけ置く。**チャット本文・コード内・共有するファイルには書かない。画面を共有するときは写り込みに一声かける（safety.md ④）
- テスト送信の1通目は必ず本人に見てもらってから、本番の通知を流し始める（safety.md ⑤の「まず小さく試す」の通知版）
- 通知は増やしすぎない。毎回鳴る通知は読まれなくなる。「成功は1日1回まとめて、失敗はすぐ」のような整理を提案する
- ウェブフックで送れるのは通知だけ。「返信を受け取りたい」「Discordから秘書に指示したい」と言われたら、それはボット方式の話なので、別のおしごとカードとして改めて相談する
- 通知が届かなくなったときは、URLの打ち間違い → ウェブフックが削除されていないか → ネット接続、の順に確認する。原因はやさしい言葉で伝え、本人を責める言い方はしない（safety.md ⑥）
