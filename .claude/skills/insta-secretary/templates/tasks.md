# タスクメモ（テンプレート）

朝のひとこと報告（`recipes/morning_report.md`）が読む台帳。1行1タスクで気軽に書く。
秘書は読むだけで、「済」への変更は本人が行う。

## 書き方

```
- [ ] やること ｜期限: 2026-09-01
- [ ] ○○さんへ返信 ｜返信待ち開始: 2026-08-28
- [x] 終わったタスクはこう
```

- 期限があるものは `｜期限: YYYY-MM-DD` を付ける
- 誰かの返事を待っているものは `｜返信待ち開始: YYYY-MM-DD` を付ける（48時間動きがないと朝の報告で再掲される）
- 完了したら本人が `[ ]` を `[x]` に変える
